> **D126: ActorContext shared-kernel value object plus authorisation decorator at use case boundary.** Bundled two-sub-commitment D-entry covering the Phase 2-A actor identity and authorisation substrate per the Decision 7 forward-compat substrate-depth classification. *Sub-commitment 1.* ActorContext is a frozen dataclass at `shared_kernel/actor_context.py` composing the existing TenantContext as a field plus three additional fields: `actor_id` (str, UUID-shaped from the Principal extracted at auth middleware), `role_list` (frozenset[str], single value "operator" at Phase 2-A populated by hardcoded auth middleware logic per the framing-time settlement on authorisation_set population mechanism), `authorisation_set` (frozenset[str], populated from a hardcoded role-to-authorisation lookup at auth middleware for Phase 2-A; lookup table activates at the role-hierarchy deferred-decisions entry's trigger). ### Commit 3: Authorisation decorator plus AuthorisationDenied translation

```
feat(p13/s44a): authorisation decorator at use case boundary plus 403 translation
```

Add `shared_kernel/authorisation.py` defining:

- `requires_authorisation(permission: str)` decorator that wraps a method whose signature includes an `actor: ActorContext` parameter. The decorator reads the `permission` string at decoration time, finds the ActorContext in the call's arguments at invocation time, and checks `permission in actor.authorisation_set`. Raises `AuthorisationDenied(permission, actor_id)` when the check fails.
- `AuthorisationDenied(Exception)` typed exception carrying the required permission and the actor_id from the failed check.

Add the HTTP 403 translation at `apps/api/_errors.py` (or current path; verify at pre-write reconciliation). The exception handler catches `AuthorisationDenied` and returns an `ErrorResponse` with `error_code="authorisation_denied"`, message includes the required permission (not the actor's full set), and the standard correlation_id plus details fields.

Add `tests/unit/shared_kernel/test_authorisation.py` covering happy path (permission in set, method executes), deny path (permission absent, AuthorisationDenied raised with correct permission and actor_id), decorator-on-async-method behaviour, decorator preserves method signature, and the AuthorisationDenied exception's attributes.

Add HTTP integration tests at the appropriate path (verify per existing test convention) for the 403 translation, exercising AuthorisationDenied through a test route and verifying the ErrorResponse shape.
