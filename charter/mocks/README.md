# charter/mocks

These HTML/markdown mocks illustrate the design language. They are **not** the specification.

`charter/design-language.md` is binding. On any conflict between a mock and the doc, the doc wins — the mock JS, copy, and persona ("Aanya Krishnan", clients Helios/Northwind) are placeholder illustration, not contract.

The standalone connections mock is personal and intentionally not committed. Build the Connections page from `design-language.md §9` plus the Settings → Connected accounts view in `app-shell-mock.html`.
